# To-Do-List

A simple and responsive To-Do List web application built using **HTML**, **CSS**, and **JavaScript**. This application allows users to add tasks, mark them as 
completed, and delete tasks with an intuitive and clean user interface.

##  Features

*  Add new tasks
*  Mark tasks as completed
*  Delete tasks
*  Save tasks using Local Storage
*  Edit existing tasks
*  Clean and modern UI design
*  Responsive layout
*  Visual indication for completed tasks (strikethrough effect)
*  Lightweight and fast (No external frameworks)

---

##  Technologies Used

* **HTML5** – Structure of the application
* **CSS3** – Styling and responsive design
* **JavaScript (ES6)** – Functionality and DOM manipulation

##  How It Works

1. Enter a task in the input field.
2. Click the **Add** or **enter** button to create a new task.
3. Check the checkbox to mark a task as completed.
4. Click the **Delete** button to remove a task from the list.
